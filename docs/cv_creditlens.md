# CreditLens — texte prêt pour le CV

## Version complète (rubrique Projets)

**CreditLens — Analyse du risque de crédit augmentée par l'IA** — projet personnel
- Conçu un entrepôt PostgreSQL 3 couches (307 511 crédits) et un modèle de scoring LightGBM
  (classes de risque A–E, explicabilité SHAP) chiffrant 6,2 Md€ de perte attendue selon la
  logique Bâle III / IFRS 9.
- Développé un agent IA text-to-SQL (LLM local + protocole MCP, accès base en lecture seule
  sécurisé) atteignant 100 % de fiabilité sur 30 questions-tests automatisées.
- Mis en place un RAG réglementaire (Bâle III, IFRS 9, AI Act) répondant avec sources citées —
  100 % de bon document retrouvé.
- Classé automatiquement 19 M de réclamations clients en 9 motifs par LLM, et construit un
  dashboard web interactif piloté par la base.
- Stack : Python, PostgreSQL, Docker, LightGBM, SHAP, Ollama, MCP, RAG — 100 % local et gratuit.
